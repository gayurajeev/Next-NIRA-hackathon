# Security Policy

## Supported Versions
Only the latest `main` branch version is actively maintained during hackathon evaluation.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security vulnerability or sensitive data exposure in NIRA:
1. Please do not open a public issue.
2. Email the core development team at `admin@nira.in` or `gayathry.rs22@gmail.com`.
3. Include details of the vulnerability, reproduction steps, and potential remediation.
4. We will acknowledge receipt within 24 hours and patch critical flaws immediately.
