# Contributing to NIRA

Thank you for your interest in contributing to **NIRA** (Neighborhood Intelligence & Response Assistant)!

## 🛠️ Code of Conduct
Please treat all team members and community participants with kindness, respect, and constructive collaboration.

## 🚀 Getting Started
1. Fork the repository on GitHub.
2. Clone your fork locally:
   ```bash
   git clone https://github.com/gayurajeev/Next-NIRA-hackathon.git
   cd Next-NIRA-hackathon
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Configure environment variables in `.env.local`:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://qjbcbmogmsqrewmntjwc.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
   ```
5. Run the development server:
   ```bash
   npm run dev
   ```

## 🎨 UI Guidelines
- Follow the **Fund My Crazy Light Theme**: Sky-blue grid paper background (`#EDF4FF`), Royal Blue hero arch (`#256BF5`), solid primary colors (Yellow, Google Blue, Green, Red).
- Absolutely NO dark mode and NO glassmorphism.
- Commits should follow the Conventional Commits specification (`feat:`, `fix:`, `docs:`, `chore:`, `refactor:`).
